# Mortgage Payoff Optimization Calculator

Tool to analyze how extra principal payments affect mortgage payoff time and total interest.

## Features
- Amortization schedule  
- Extra payment impact analysis  
- Interest savings vs. baseline  
- Payoff time reduction  
- Strategy comparison  

## Tech Stack
- Python  

## Use Cases
- Mortgage planning  
- Financial education  
- Debt payoff analysis  

## Future Work
- Visualization, Variable-rate support, CSV/PDF export, Web UI
